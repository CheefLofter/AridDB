Running the documentation locally

This page loads its content from docs.md, so it may not load when you open the HTML file directly in a browser. Start a local server from the project folder instead.

Linux / macOS

python3 -m http.server 8000

Windows

py -m http.server 8000

Then open http://localhost:8000/docs/docs.html in your browser.
