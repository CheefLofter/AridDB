Notes from the project.

These examples show the basic idea behind AridDB: create a local file, save some data, and read it back with familiar Python methods.

Quick start AridDB AridKV

Quick start

Install the source in your project, then create a database by giving it a filename. The local file is created automatically when it does not exist.

from AridDB import AridDB

db = AridDB("database")
db.addRow(["Alice", 30])
print(db.readRow(0))

AridDB

Use row-based storage for simple, ordered records. Each new row receives an index automatically.

db.addRows([["Alice", 30], ["Sam", 28]])
db.editRow(["Alice", 31], 0)
db.deleteRow(1)
db.dumpDB()

AridKV

Use the companion key-value store when your records are naturally represented as dictionaries.

from AridKV import AridKV

store = AridKV("kvstore")
store.addRecord({"theme": "pink"})
store.readRecord(0)
